
# Sahaay – Cooperative Gig Services Platform

**Developed by Team ByteForge**

Sahaay is a web-based platform that connects customers with skilled local workers for household and community services. It helps customers find workers and request services while allowing workers to manage job requests and applications.

## 🚀 Features

### 👤 Customer
- Browse different types of local workers.
- View worker profiles, ratings, experience, availability, and prices.
- Request services and manage bookings.
- Access emergency SOS and location features.

### 🛠️ Worker
- View a personal dashboard.
- Apply for jobs and upload verification documents.
- Manage job requests and orders.
- View location and booking details.
- Use OTP and emergency SOS features.

### 🔐 Admin
- View and manage customer and worker information.
- Review worker applications and verification status.
- Manage service requests and assign jobs.
- Update worker profiles, prices, and availability.
- View emergency SOS alerts.

## 💻 Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP (for backend integration)
- **Database:** MySQL
- **Development Tools:** Cursor, XAMPP, Git, GitHub

## ⚙️ Installation and Setup

1. Install [XAMPP](https://www.apachefriends.org/).
2. Clone this repository:

   ```bash
   git clone https://github.com/Darshandodaman/Byteforge.git
   ```

3. Move the project folder into the XAMPP `htdocs` directory.
4. Start Apache and MySQL from the XAMPP Control Panel.
5. Configure the database connection in your PHP configuration file.
6. Open your browser and visit:

   ```text
   http://localhost/Byteforge/
   ```

## 🎯 Project Objective

The main objective of Sahaay is to make household and community services easier to access, help local workers find employment opportunities, and provide a convenient platform for connecting customers and service providers.

## 🚨 Emergency SOS

Sahaay includes an SOS interface designed to help customers and workers share their location and raise emergency alerts. Real-time notifications and emergency integrations require a properly configured backend.

## 🔒 Security Note

Authentication, role-based access, document verification, and emergency notifications must be securely implemented on the server before production use. Do not store passwords, API keys, or private documents in public source code.
